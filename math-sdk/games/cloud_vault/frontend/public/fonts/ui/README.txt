Noto UI fonts for Paradise Bloom.
Families: Noto Sans Arabic, Noto Sans Devanagari, Noto Sans JP, Noto Sans KR, Noto Sans SC, Noto Sans.
Source: Google Fonts official CSS API, with a text subset covering the shipped translations.
Weights: 400–900. Font files are bundled locally; the game makes no requests to Google Fonts.
Each accompanying OFL-*.txt contains that family's copyright notice and SIL Open Font License 1.1.
Generation date: 23 October 2026.

cyrillic, cyrillic-ext, vietnamese), downloaded as the Google Fonts woff2 subsets with their unicode ranges
(lora-700-*.woff2, nunito-900-*.woff2; licences OFL-lora.txt, OFL-nunito.txt). Added 26 October 2026.
