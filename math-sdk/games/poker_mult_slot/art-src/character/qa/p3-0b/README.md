# P3-0b — baseline

База: `f2d6bdab35bc17d0bcb4a00974ade3936a264409`, ветка `codex/character-a-p3`. Изменения ткани ещё не применены. Анимаций и ключей нет.

## Воспроизведение

Из папки `art-src/character`: `node tools/check-p3-coverage.cjs --baseline`. Playwright и sharp доступны в bundled Node; Chrome уже установлен. `P3_CHROME_PATH` позволяет указать его путь.

Официальный vendored `spine-canvas-3.8.js` не изменён. Вход — JSON без stamp версии. Рендер: внутренняя точность 4×, вывод 930×1691, 1.6558249556475457 ед. Spine/px. Это подавляет швы клиппинга треугольников Canvas; профиль одинаков для «до» и «после». Альфа сохраняется отдельно; кропы композитятся на RGB(48,61,72), кандидат обозначен розовым.

Внутренние компоненты: alpha <200, 4-связность, ≥4 px, отсутствие связи с границей холста. Краевые кандидаты: closing точным евклидовым диском 12 px минус силуэт, затем вычитается setup residual. Включены все 11 подрисовок.

Сетка: arm −10/0/+10; elbow с шагом 10°; hand −20/−10/0/+10/+20. Углы каждой руки × chest ±8. Отдельно chest ±4/±8 и head ±5/±10. BASE/default и idle — вся сетка; FS — углы и одиночные крайние положения. Стресс-позы вынесены из гейта.

| fs | 65 | 1667 | 2277 | 133 |
| fs_idle | 65 | 1864 | 2535 | 188 |

Все кандидаты имеют кроп, mask и причину в `before/coverage.json`. Классификация краёв опирается на обратное отображение в текстуру и исходный pixel ownership: ≥25% исходного непрозрачного покрытия означает открытую ткань; преимущественно прозрачный исходный контур — легитимная внешняя вогнутость. Внешние точки оболочки отмечены как предложения расширения и требуют повторного рендера после расширения.
