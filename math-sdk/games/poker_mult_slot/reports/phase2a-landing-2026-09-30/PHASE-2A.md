# Phase 2A — Godot landing grammar in Pixi

Landing motion milestone; **full renderer parity is not accepted**. The normal React application and Godot fallback are unchanged. There are no engine, math, wallet, new-art or audio-bank edits in this sub-phase.

The Pixi presentation clock now uses Godot’s live strip phase, 205-unit cells, 2600 / 3400 travel speed, quadratic 180 / 60 ms acceleration, 550 / 120 ms minimum travel, 160 / 45 ms column stagger, and 80 / 30 ms last-column breath. Braking covers only the remainder of the current cell with sine-in easing and 50–140 ms approach, then the final wrap fires each column’s real stop sound. The overshoot is +0.03 cell over 30 ms, followed by a 70 ms cubic-out settle. Squash is 1.04 / 0.97, with 50 ms attack and 120 ms release, 12 / 6 ms row stagger and half-length turbo bounce. As in the actual Godot source, row squash starts at brake start (its comment calls this collision); column stop sounds fire at the visible wrap. Shake is 0.8 / last-column 2.2; 5.0 is used only when the stopped column contains a Joker.

Real faces are recycled during travel. Target-free travel cannot settle or snap to an invented result. Cancellation restores the previous 25 real cards and multipliers. The actual result is inserted only after the React owner supplies it; landing never resets strip position. Ordinary completion preserves the remaining squash instead of repainting the board. A true-target snap produces the exact final board without replaying stop sounds. The renderer has no wallet API.

The standalone audition includes a 1200 ms visual wallet mock and rejection; this is separate from the normal application’s real RGS path. Its first-frame check is **still open**: one intermediate run measured 45.37 ms, subsequent runs 53–59 ms; the final run measured **59.46 ms**, above the required 50 ms. The test requires >2000 materially changed pixels in the card region, not background animation or JavaScript dispatch time. Do not treat the isolated passing run as acceptance. The Phase 0.5 real-wallet Godot measurement remains in its original report. The reversible 4-CSS-pixel nudge transfers into the live strip phase at result arrival without a positional jump. WebGL work is briefly deferred only while target-free feedback begins; real results immediately resume the ticker.

Final browser checks: actual painted faces equal all 25 engine payload cards in ten trials; exactly five collision callbacks per natural landing; exactly one settled signal; all legacy reel-stop audio sources start within one browser frame of their corresponding visible collision; heavy shake is Joker-only. No page/console errors or missing assets. Normal / turbo / recorded desktop and portrait are approximately 59.2–60 FPS, p95 16.7–16.8 ms. The short reduced-motion trial measured 43.4 FPS / p95 33.4 ms, with no squash or shake; this remains a measurement to audit during live integration. These are local Chrome measurements, not a real-phone result.

TypeScript and 36 tests across five suites pass. Separate slice production build passes.
