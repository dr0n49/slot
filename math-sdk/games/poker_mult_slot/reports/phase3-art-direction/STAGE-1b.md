## Качество источников и ограничения

Queen A: отдельно отмечены J♥ (плотнее правая глазница) и K♣ (усы пересекают мелкие детали рта). Это места для проверки, не утверждение о доказанном дефекте. Мелкая гравировка в коронах / одежде теряется на 60×85, исходный alpha/ореол сохранён. Отклонённые промежуточные K♥/K♦ с лишними костями не используются. Queen B доступна в архивной ссылке как одиночный прежний кандидат.

Прежняя колода: 444×624 на полную карту, люди с гримом Calavera вместо скелетов, стиль между мастями различается. Отдельно отмечены K♠ (воротник с похожими на псевдобуквы формами), J♣/K♥ (плотные зубы / рот), Q♦ (сливающиеся контуры пальцев). Все лица доступны крупно; ничего не скрыто ретушью.

Три упомянутых цветовых референса в доступных вложениях отсутствовали. A/B/C построены по текстовому описанию; композиция и элементы новых сцен нарисованы самостоятельно.

Числовой порог Stake ACP отсутствует по ответу пользователя. **Официальное прохождение автоосветления не заявляется.** В `review-1b/brightness.json` сохранены Y′ 0.2126R + 0.7152G + 0.0722B, линейная sRGB-светимость, p95 и области сравнения. После уменьшения широкой дымки все A/B/C светлее текущей игры: desktop **55.90–60.80 против 20.14**, portrait **55.07–60.11 против 15.51**, шкала 0–255. Доска / локальное окружение: **2.73–2.97:1 desktop, 3.07–3.71:1 portrait** по линейной средней яркости с +0.05; это диагностическое отношение областей, не WCAG-оценка текста. p95 доски выше p95 чистой сцены во всех шести сравнениях. Отдельные средние для каждого Stake-формата показаны на странице.
