# Casino sounds

16-bit PCM WAV, 22.05 kHz mono. Loaded by `src/game/casinoAudio.ts`.
To replace a sound, drop a new file with the **same basename** (`.wav`).

| File | Used for |
|------|----------|
| `background_music.wav` | Looping casino BGM (20 s loop) |
| `card_deal.wav` | Normal card deal slap (per card) |
| `card_deal_turbo.wav` | Turbo/Speed deal slap |
| `button_click.wav` | UI buttons |
| `win_small.wav` | Jacks or Better … Flush |
| `win_big.wav` | Full House, Four of a Kind, Straight Flush, Royal Flush |
