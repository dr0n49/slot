## 6. Риски (тайминг-бюджет / производительность)

1. **Dim не-выигравших (3.4.5)**: в проекте нет ни одного Pixi-фильтра; ColorMatrixFilter на 30 спрайтах — риск для FPS на low/mid. Решение: pre-baked desaturated-версии символов в атласе + swap текстуры, затемнение через `tint` — без фильтров, в бюджете.
2. **Watchdog 90/120 s + worst-case 81 s**: запас всего 9 s. Фазы бласта (anticipation фитиль → impact → debris → rung reaction → aftermath) обязаны считаться в `COST` pacing.test.ts; фитиль уровня 1 — ≤400 ms, иначе сжать.
3. **Пул частиц**: cap 380 (high tier). Deep-blast + MASSIVE одновременно — только повторным использованием `burst/smoke/shockwave`, без новых систем; `burstScale` уже режет на слабых устройствах.
4. **Атласы**: сейчас 13 отдельных PNG без атласа; переход на атлас затрагивает только `textures.ts` (изолирован), но нужно успеть до перерисовки символов, чтобы не экспортировать дважды.
5. **Текст**: вся типографика DOM — утечек Pixi-текста нет, но `LadderPanel` перерисовывается каждый тик бласта; тяжёлые CSS-эффекты (drop-shadow на 7 плашек) могут стоить кадров — мерить на 1024×768.
6. **Палитра vs 5 самоцветов**: тёплая гамма не даёт 5 различимыхhue — нужно решение (см. вопросы).
7. **perf.ts не умеет мерить FPS/heap** — для §16 добавлю компактный хук (rAF-счётчик + `performance.memory` где есть) до стресс-прогона.
8. **Git**: `~/slot/ws` — вложенный репо внутри большего `~/slot` (там `ws/` лежит untracked) — диффы W6 смотрятся изолированно, как и задумано.
