**Вывод: игра уже 5 барабанов × 6 рядов = 30 позиций. Конвертировать нечего.**

Пункт 6 задания исходит из того, что сейчас в игре 6 барабанов × 5 рядов. Это не так.
Ниже — проверка каждого слоя, который зависит от геометрии. Никакие файлы для этой
проверки не менялись.

## 1. Математика

| Что | Где | Значение |
|---|---|---|
| Число барабанов | `math_params.py:30` | `NUM_REELS = 5` |
| Рядов на барабан | `math_params.py:31` | `NUM_ROWS = 6` |
| Конфиг борда | `game_config.py:36-37` | `num_reels = 5`, `num_rows = [6, 6, 6, 6, 6]` |
| Максимум скаттеров | `game_config.py:61` | `num_reels * NUM_ROWS = 30` |
| Веса лент | `math_params.py:103-105` | по одному словарю на каждый из 5 барабанов |

Ленты на диске: `reels/BR0.csv` — **100 строк по 5 значений**, то есть одна колонка на
барабан, 100 ячеек в ленте. Строка файла — это позиция ленты, а не ряд борда.

Борд в опубликованных книгах: `reveal.board` — **5 элементов, в каждом 8 ячеек**
(6 рядов + по одной padding-ячейке сверху и снизу). Проверено на боевом
`books_base.jsonl.zst`.

Индексация везде `board[reel][row]`, `reel ∈ 0..4`, `row ∈ 0..5`:

* отрисовка борда — `src/calculations/board.py`: `board[i] = [0] * num_rows[i]`,
  `board[reel][row] = strip[(pos + row) % len]`;
* ways — `game_calculations.py`: внешний цикл по барабанам `enumerate(self.board)`,
  внутренний по ряду; выигрыш считается слева направо от барабана 0;
* каскад — `src/calculations/tumble.py`: длина колонки после тамбла сверяется с
  `num_rows[reel]` и при расхождении бросает исключение;
* кеги, скаттеры, порода, wild — все обходят борд как `for reel, column: for row, sym`.

## 2. Фронтенд

Геометрия не захардкожена нигде: всё приходит из сгенерированного
`mathConfig.generated.ts` (`numReels: 5`, `numRows: 6`).

| Что | Где |
|---|---|
| Источник | `game/config.ts` → `GAME.numReels`, `GAME.numRows`, `GAME.paddedRows = numRows + 2` |
| Размер борда | `engine/layout.ts:43-49` — ширина `cell * numReels`, высота `cell * numRows` |
| Сцена | `engine/board.ts:11-12` — `REELS = GAME.numReels`, `ROWS = GAME.numRows` |
| Координаты | `engine/board.ts` — `cx(col) = cell * (col + 0.5)`, `cy(row) = cell * (row + 0.5)` |
| Проверка тамбла | `boardLogic.ts:22` — колонка обязана быть длиной `paddedRows` |
| Текст в инфо | `InfoDialog.svelte:126` — «5 reels × 6 rows (30 symbol positions)» |

Поиск по игровым файлам не нашёл ни одного захардкоженного `5`, `6` или `30`,
относящегося к геометрии поля.

## 3. Тесты

Существующий тест `books.test.ts` уже утверждает геометрию и проходит:

```
✓ math-sdk books > every board is 5 x 8 padded rows of known symbols, and tumbles fold cleanly
```

(5 барабанов × 8 = 6 рядов + 2 padding.)

Добавленный в W2 тест проверяет то же самое на всей библиотеке мок-книг:

```
✓ folds a complete board of the right geometry for every book
     board.length === GAME.numReels (5), каждая колонка === GAME.paddedRows (8)
```

## 4. Визуальная проверка

Blast Ladder стоит слева отдельной панелью и в борд не входит.
